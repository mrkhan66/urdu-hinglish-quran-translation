# Noor — Mukammal Quran (Roman Urdu / Hinglish Tarjuma)

Noor ek modern, responsive web application hai jisme mukammal Quran Majeed Arabic matn, Roman Urdu / Hinglish tarjuma aur Urdu script ke saath shamil hai.

## Features
- **114 Surahs**: Mukammal Quran Majeed ka matn aur tarjuma.
- **Roman Urdu / Hinglish Translation**: Har kisi ke liye aasan roman urdu me tarjuma.
- **Urdu Script Translation**: Traditional urdu script translation bhi dastyab.
- **Audio Recitation**: Ayah-by-ayah audio recitation.
- **Search & Filter**: Surah aur Ayah search palette.
- **Bookmarks & Notes**: Apni pasandeeda aayat ko save karein aur personal notes add karein.
- **Reading Progress Tracker**: Daily reading aur surah completion tracking.
- **Offline Capable & Fast**: Client-side single bundle architecture.

## Tech Stack
- React 19 + TypeScript
- Vite 7 + Tailwind CSS v4
- Framer Motion
- Lucide React Icons

## Local Development
```bash
# Dependencies install karein
npm install

# Dev server start karein
npm run dev

# Production build generate karein
npm run build
```
